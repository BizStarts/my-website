# Google Форма подключена

Рабочий вариант отправляет заявку обычным POST-запросом прямо в Google Форму. Отдельный Google Apps Script не нужен. Настройки находятся в `dist/config.js` → `googleForm`.

Форма владельца: https://docs.google.com/forms/d/1Ums8vlFJ8WD4pKooGqBVdIOpYEIMLQRiG_DEFx4xbOc/edit

Поля проверены по публичной странице формы:

- `entry.1908189698` — «Ваше имя.»
- `entry.2034992491` — «Ваш телефон».

Поскольку в форме только два текстовых поля, предпочтительный мессенджер записывается на отдельной строке вместе с телефоном: `Удобный способ связи: Telegram` (или Макс / WhatsApp). Данные не теряются. После отправки сайт переходит на страницу Google, где отображается фактическое подтверждение приёма или ошибка. Сайт не показывает вымышленное подтверждение и не использует скрытую отправку без проверки ответа.

27 октября 2026 года выполнена одна реальная тестовая отправка. Google вернул HTTP 200 и «Ответ записан». Тест: `Website connection test - can be deleted`, фиктивный номер `+70000000000`, способ связи `Telegram (TEST)`. Эту запись можно удалить во вкладке «Ответы».

Если вопросы удалить и создать заново, их ID изменятся: потребуется обновить конфигурацию. Форму нужно оставлять доступной для посетителей и принимающей ответы.

`google-form.gs` сохранён как дополнительный вариант: он позволяет создать отдельные поля для мессенджера и согласия, а также показывать подтверждение на самом сайте. Для него нужен запуск и развёртывание в аккаунте владельца, затем URL `/exec` в `googleScriptUrl`. Пока это поле пустое, работает проверенная прямая отправка.

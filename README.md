# Кредитные решения — помощь в получении кредита

Адаптивный статический лендинг. Откройте `dist/index.html` или запустите сервер из этого каталога: `node preview.cjs`.

Форма готовит письмо на baranov_95msk@mail.ru через почтовое приложение посетителя. Автоматической отправки, хранения заявок и аналитики нет. Телефон: +7 (916) 038-77-54.

Визуальное название — «Кредитные решения». Юридические реквизиты ИП Баранова сохранены. Главная иллюстрация и аватары заменены на фотографичные изображения, созданные ИИ; это не фотографии реальных клиентов или сотрудника. Файлы и итоговые промпты перечислены в `IMAGE-PROMPTS.md`.

Внизу добавлен информационный перечень банков, без заявления о подтверждённом партнёрстве. Росбанк указан в составе Т-Банка со ссылкой на источник.

До рекламного запуска подтвердите показатель 87% и период расчёта; текущий блок прямо помечен как предварительный. Точный адрес и стаж не придуманы: добавьте реальные сведения. В разделе отзывов размещены три явно обозначенных демонстрационных примера с вымышленными именами и текстами. Замените их реальными отзывами, согласованными с авторами, перед публикацией. Реквизиты перенесены из предоставленного изображения.

Для автоматического приёма заявок потребуется серверная обработка и согласованные документы об обработке персональных данных. Google Fonts используется для шрифта; при отсутствии сети работает Arial.
